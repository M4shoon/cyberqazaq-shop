# CyberQazaq — Компьютер бөлшектерін сататын интернет-дүкен

Flask (Python) негізінде жазылған толыққанды e-commerce веб-қосымша. Пайдаланушы компьютер бөлшектерін (видеокарта, процессор, жад, SSD, монитор, тышқан, пернетақта, гарнитура) қарап, себетке салып, тапсырыс бере алады. Жобаның ерекшелігі — бюджет пен мақсатыңа (ойын/стриминг/жұмыс) қарай компьютер жинап беретін **AI Builder** көмекшісі.

## Мүмкіндіктер

- 🛒 Тауар каталогы, себет, тапсырыс беру ағыны
- 🤖 **AI Builder** — бюджет пен қолдану мақсатына сай GPU/CPU/RAM/SSD-ті автоматты таңдап, әр бөлшекті қазақша түсіндіреді
- 🧾 Тапсырыс үшін PDF чек генерациясы (`reportlab`)
- 📧 Жаңа тапсырыс түскенде email-ге хабарлама жіберу (Gmail SMTP)
- 🔐 Логинмен қорғалған админ панелі (тауарлар мен тапсырыстарды басқару)

## Технологиялар

`Python`, `Flask`, `reportlab` (PDF генерация), `HTML/CSS/JS` (шаблондар, серверлік рендеринг)

## Орнату

```bash
git clone <repo-url>
cd cyberqazaq
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env          # .env файлын толтыр (төменде қара)
python app.py
```

Қосымша `http://localhost:5000` мекенжайында іске қосылады.

## Айнымалы орталар (.env)

`.env.example` файлын `.env` деп көшіріп, өз мәндеріңді қой:

| Айнымалы | Сипаттамасы |
|---|---|
| `SECRET_KEY` | Flask сессиясын қорғайтын кездейсоқ жол |
| `ADMIN_USER`, `ADMIN_PASS` | Админ панельге кіру деректері |
| `EMAIL_SENDER`, `EMAIL_PASSWORD`, `EMAIL_RECEIVER` | Тапсырыс хабарламалары үшін Gmail деректері (App Password қажет) |
| `ANTHROPIC_API_KEY` | (міндетті емес) Claude API кілті. Жоқ болса, AI Builder локалды логикамен жұмыс істейді |
| `FLASK_DEBUG` | `1` болса debug қосылады (тек дамыту кезінде) |

`.env` файлы `.gitignore`-де тұр — оны ешқашан GitHub-қа жүктеме.

## AI Builder қалай жұмыс істейді

1. Клиенттің сұрауынан бюджет, категория және қолдану мақсаты (esports/streaming/creative/aaa) анықталады.
2. Дүкен каталогы + ережелер Claude-қа жүйелік промпт ретінде беріледі, Claude қатаң JSON қайтарады (`analysis`, `single_product`, `full_setup`).
3. Claude қолжетімсіз болса (кілт жоқ, timeout, дұрыс емес JSON), `explain_product()` және локалды таңдау логикасы fallback ретінде жауап береді.

## Жоба құрылымы

```
app.py              # Негізгі Flask қосымшасы, барлық роуттар
generate_pdf.py      # Тапсырыс чегін PDF-ке айналдыру
data.json             # Тауарлар каталогы (GPU, CPU, RAM, SSD, т.б.)
templates/            # HTML беттер (Jinja2)
static/                # CSS, JS, суреттер
```

## Белгілі шектеулер

- Деректер қоры орнына бір `data.json` файлы қолданылады — production үшін SQLite/PostgreSQL сияқты нақты дерекқорға көшіру ұсынылады.
- Аутентификация қарапайым сессия негізінде, парольдер хэштелмейді — өндірістік ортаға шығарар алдында `werkzeug.security` (`generate_password_hash`) қолдану керек.
